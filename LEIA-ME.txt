LEITOR OFFICE — atualização de leitura Word e PowerPoint

O QUE FOI ALTERADO
- Leitura local dos formatos .DOC, .DOCX, .PPT e .PPTX usando a biblioteca Ream (reamkit).
- O leitor converte o conteúdo para HTML dentro do próprio aparelho, sem enviar o documento para um servidor.
- A conversão HTML inclui conteúdo estruturado e imagens presentes no fluxo do documento, quando suportadas pelo leitor.
- Imagens, tabelas e elementos SVG recebem ajuste responsivo para telas de celular.
- O aplicativo continua somente para leitura; não edita nem sobrescreve o arquivo original.
- Manifesto inclui os quatro tipos MIME e extensões para associação de arquivos.
- Código JavaScript recebe arquivos pela Launch Queue quando o APK/TWA Android é gerado com filtros de arquivo compatíveis.

IMPORTANTE SOBRE O ANDROID
O manifesto sozinho não registra o app como opção “Abrir com” no Android. O pacote Android precisa ser reconstruído com uma versão do Bubblewrap que gere os intent-filters dos file_handlers (Bubblewrap 1.22.6 ou superior) e a integração TWA para encaminhar os URIs à Launch Queue. Depois, gere um novo APK/AAB no PWABuilder/Bubblewrap.

MANTER O MESMO APLICATIVO INSTALADO
- Repositório: alexcfrj-bot/leitor-office
- URL: https://alexcfrj-bot.github.io/leitor-office/
- Package ID: io.github.alexcfrj_bot.leitoroffice
- Ao gerar atualização Android, NÃO escolha uma chave de assinatura nova. Use a mesma signing.keystore da versão instalada e mantenha o mesmo Package ID e versionCode maior.
- Faça backup seguro da keystore e das informações da chave; não as envie ao GitHub.

LIMITAÇÕES
Nenhum leitor de documentos garante reprodução perfeita de todos os recursos proprietários do Office. Arquivos com macros, objetos OLE, SmartArt, fontes ausentes, vídeos/áudios incorporados, proteção por senha ou elementos especiais podem ter diferenças ou não ser exibidos. Teste com cópias dos arquivos originais.

DEPENDÊNCIA
O motor Ream é carregado por CDN na primeira abertura com internet. O service worker guarda os recursos que forem carregados, mas o primeiro uso precisa de conexão. O aplicativo não envia o arquivo para servidor; a leitura acontece no navegador do aparelho.
