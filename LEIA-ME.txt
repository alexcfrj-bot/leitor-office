LEITOR OFFICE — candidato de correção dos visualizadores DOCX e PPTX

O QUE ESTA VERSÃO MUDA
- DOCX: usa docx-preview para renderizar páginas, imagens incorporadas, tabelas, cabeçalhos e rodapés no navegador.
- PPTX: usa PptxViewJS para desenhar um slide por vez em canvas, com navegação Anterior/Próximo.
- DOC e PPT antigos: continuam usando Ream como conversor de compatibilidade para HTML. A fidelidade desses formatos binários ainda precisa ser testada.
- A leitura continua local no navegador; os arquivos não são enviados pelo código do aplicativo.
- Nenhum APK foi gerado nesta etapa.

IMPORTANTE
Esta é uma versão candidata para testes, não uma garantia de compatibilidade total com todos os recursos do Microsoft Office. SmartArt, macros, objetos OLE, animações, transições, fontes não instaladas, gráficos complexos e elementos especiais podem apresentar diferenças.

DEPENDÊNCIAS
Os renderizadores são carregados por CDN. O primeiro uso de cada biblioteca exige internet. Depois, o cache do navegador/service worker pode armazenar os recursos, mas o funcionamento offline precisa ser validado no aparelho.

TESTES OBRIGATÓRIOS ANTES DE GERAR APK
1. DOCX com imagens inline e flutuantes, tabelas, cabeçalho e rodapé.
2. PPTX com fotos, fundos, formas, gráficos e múltiplos slides.
3. DOC e PPT binários antigos, incluindo imagens.
4. Android: testar seleção manual e recebimento via Abrir com/Compartilhar após reconstruir a TWA com filtros de arquivos.

ANDROID / APK
O manifesto declara os quatro formatos, mas isso não basta para o Android mostrar o app em Abrir com. O pacote Android precisa suportar os filtros file_handlers e encaminhar os arquivos à Launch Queue. Ao atualizar o APK, manter Package ID io.github.alexcfrj_bot.leitoroffice, usar versionCode maior e a mesma chave de assinatura da instalação existente. Nunca enviar signing.keystore ao GitHub.
