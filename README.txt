LEITOR OFFICE — versão inicial PWA

Formatos:
- DOCX: visualização de texto e imagens com Mammoth.js.
- XLSX: visualização das abas e exportação da aba atual para CSV com SheetJS.
- PPTX: visualização no navegador com pptx-preview.

PUBLICAÇÃO:
1. Extraia este ZIP.
2. Envie os arquivos e a pasta icons para a raiz de um NOVO repositório GitHub, separado dos outros aplicativos.
3. Ative Settings > Pages > Deploy from a branch > main > /(root).
4. Abra o endereço HTTPS no PWABuilder para gerar o APK Android.

PRIVACIDADE E LIMITES:
Os documentos selecionados são processados no próprio aparelho; o app não os envia para um servidor. Na primeira utilização, precisa de internet para carregar as bibliotecas de leitura por CDN. A interface básica pode ser armazenada em cache. A renderização de documentos complexos pode diferir do Microsoft Office; macros, fórmulas recalculadas, animações, objetos incorporados e arquivos protegidos por senha podem não ser exibidos. Esta versão é um visualizador, não um editor completo do Office.
